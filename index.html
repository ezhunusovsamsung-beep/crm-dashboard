Лиды, созданные за период, по ответственному за лид. Нажми на отдел, чтобы раскрыть менеджеров (МОП) в разрезе. Качественный — статус «Качественный лид». Некачественный — «Не актуально (уже купили)», «Неплатежеспособный», «Не соответствует профилю работы», «Неверный номер, недоступен». Повторные считаются отдельно, остальное — «в работе». Строка «Не МОП» — колл-центр, биржи и прочие ответственные вне ростера.

Команды по пайплайнам

Каждый столбец — сумма показателя по команде; сегменты — вклад каждого из 2 пайплайнов.

Сравнение команд — нормализованные показатели

Абсолютные числа не сравнимы напрямую: команды отличаются числом менеджеров (2–9 человек) и размером портфеля (50–347 сделок). Здесь те же данные пересчитаны в доли и ставки.

Полная детализация

5 команд × 2 пайплайна × 6 корзин, плюс сводные итоги по команде и по всем командам.

Методология. «Сегодня» — 25.09.2026. Для каждой сделки в статусе «в работе» (по каждому из 2 пайплайнов) берётся минимальный (ближайший) срок среди её незавершённых дел, затем сделка попадает в одну из 6 корзин — как в разделе Bitrix «Дела»: Просрочены (срок раньше сегодня), На сегодня, На этой неделе (пн–вс текущей недели), На следующей неделе (пн–вс следующей недели), Позже (дальше следующей недели), Без дел (нет ни одного незавершённого дела).
Все данные получены напрямую через REST API вебхука Bitrix24 (nkb.bitrix24.kz) — без ручной навигации по интерфейсу CRM: списки сделок по фильтрам команда+пайплайн (crm.deal.list) и список незавершённых дел по сделкам (crm.activity.list). Лимиты нагрузки на МОП — суммарное число активных сделок (crm.deal.list по всем воронкам), контактов (crm.contact.list) и компаний (crm.company.list), закреплённых за менеджером.
