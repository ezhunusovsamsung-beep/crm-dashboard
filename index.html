Просроченные и без дел — по МОП

Число просроченных сделок и сделок без единого дела по каждому менеджеру, срез на дату снимка.

Наблюдения

Ключевые отклонения, видимые в данных на дату снимка.

Команды по пайплайнам

Каждый столбец — сумма показателя по команде; сегменты — вклад каждого из 4 пайплайнов.

Сравнение команд — нормализованные показатели

Абсолютные числа не сравнимы напрямую: команды отличаются числом менеджеров (2–9 человек) и размером портфеля (50–347 сделок). Здесь те же данные пересчитаны в доли и ставки.

Полная детализация

5 команд × 4 пайплайна × 6 корзин, плюс сводные итоги по команде и по всем командам.

Методология. «Сегодня» — 25.09.2026. Для каждой сделки в статусе «в работе» (по каждому из 4 пайплайнов) берётся минимальный (ближайший) срок среди её незавершённых дел, затем сделка попадает в одну из 6 корзин — как в разделе Bitrix «Дела»: Просрочены (срок раньше сегодня), На сегодня, На этой неделе (пн–вс текущей недели), На следующей неделе (пн–вс следующей недели), Позже (дальше следующей недели), Без дел (нет ни одного незавершённого дела).
Все данные получены напрямую через REST API вебхука Bitrix24 (nkb.bitrix24.kz) — без ручной навигации по интерфейсу CRM: списки сделок по фильтрам команда+пайплайн (crm.deal.list) и список незавершённых дел по сделкам (crm.activity.list).
